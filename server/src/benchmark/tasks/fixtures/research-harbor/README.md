# research-harbor

The paper set for the `research-cited-summary` task: five invented papers on
an invented speech benchmark (Harbor), as a Better BibTeX JSON export
(`library.json`) with one two-page PDF each (`pdfs/`) and what
`pdftotext -enc UTF-8` (poppler 24.02) printed for them (`pdftotext/`, used
where poppler is not installed). One paper holds the answer; two are near
misses. `build.js` regenerates every file from the text in it.

Provenance and licence: written for this benchmark; every title, author, DOI
(Crossref's `10.5555` test prefix) and sentence is invented. CC0 1.0.
