# physics-projectile

The statement of a projectile problem with quadratic drag, ingested as a
physics problem node for the `physics-projectile-range` task. The reference
answer (84.659 m, computed independently with SciPy's `solve_ivp` at rtol and
atol 1e-12) lives in the task catalog, not here, so no arm can read it.
